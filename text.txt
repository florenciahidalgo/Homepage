Data Managment text:
A data project always start with a data enginering step. You need to harvest data and store it in an adequate format to be able to use it
I can help you to..
Harvest data from different sources like APIs, databases or messy Excel spreadsheets.
                      Reformat and reshape data to make further analyses easier.
                      Clean datasets removing outliers and abberant data
                      Create reproducible data preparation workflows
                      Automatize the creation of data related reports
Example:
            I collected tweets containing the #surffor 9 months to study how surfers use
            social media. I used the twitter API and made the data collection automatic
            thanks to a personnal webserver and a custom R script.
            I created a dashboard for a company called Terres Inovia. It is directly
            plugged on their SQL database and allows to access its information in real time.
